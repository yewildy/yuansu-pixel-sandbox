## 1. 仿真模型总述（Simulation Model）

### 1.1 元胞自动机（Cellular Automaton）
- 网格：$W \times H = 320 \times 180 = 57{,}600$ 格，四邻域（von Neumann）为默认；粉末/液体/气体移动使用 3–5 邻域（见 §5）。
- 每格状态为一个定长记录：

| 字段 | 类型 | 说明 |
|---|---|---|
| `element` | `Uint8Array` | 元素 ID（1–30，见 §4） |
| `temp` | `Float32Array` | 温度，单位 **°C**，范围 $[-200, 2000]$（**必须浮点**，见 §13.4 与审查 F15） |
| `age` | `Uint16Array` | 寿命/年龄计数器（tick），语义随元素定 |
| `flags` | `Uint8Array` | bit0 = 本帧已移动标记；bit1 = 本帧已反应标记 |

- 采用 **Structure-of-Arrays（SoA）** 布局，主循环零 `new`（见 `DESIGN.md` §9.2）。

### 1.2 tick 定义
- 仿真以**固定步长**推进：`TICK_HZ = 60`，即 $dt = 1/60\ \text{s} \approx 16.67\ \text{ms}$。
- 渲染与仿真解耦：使用累加器（accumulator）模式。每帧 `accumulator += realDt`，`while (accumulator >= dt) { step(); accumulator -= dt; }`，并设 `MAX_SUBSTEPS = 4` 防止螺旋死亡（掉帧时丢步而非卡死）。

### 1.3 每 tick 更新顺序（Update Order）
严格按以下顺序执行（顺序影响结果，不可调换）：

```
1. clearFlags()                          // 清空 flags 的所有 bit
2. movePass()                            // 物态移动（自下而上，x 扫描方向逐帧交替）
3. reactionPass()                        // 化学反应（按 §9 优先级）
4. lifePass()                            // 生命/植物/病毒（§10）
5. thermalPass()                         // 导热计算 → nextTemp（§6）
6. phasePass()                           // 相变判定（读 nextTemp，写 element）（§7）
7. relaxAndClamp()                       // 环境弛豫 + 温度钳制（§6.3）
8. swap temp ↔ nextTemp
9. agePass()                             // 全格 age++（有上限者）
10. windPass()                           // 气体平流（§11）
```

### 1.4 扫描方向与「已移动」防重复
- **自下而上**：`movePass` 按 `y = H-1 → 0` 遍历。理由：粉末/液体向下运动，自下而上处理可让下方先落定，避免同帧内一个粒子被移动多次。
- **水平方向逐帧交替**：偶数 tick 从左到右（`x = 0 → W-1`），奇数 tick 从右到左（`x = W-1 → 0`）。这是**消除方向偏置**的关键——否则所有液体都会倾向一侧漂移。交替是免费且确定的，不引入随机。
- **「本帧已移动」标记**：任一格被写入（移动/交换/生成）后，目标格的 `flags.bit0 = 1`。`movePass` 只处理 `bit0 == 0` 的格。防止「A 移到 B，B 同帧又移走」导致的穿越与双跳。
- 同类 `reactionPass` 使用 `flags.bit1`，防止同一格一帧内触发多条反应。

### 1.5 确定性
- 所有「随机」均为**确定性哈希**：以 `(x, y, elementId, tick)` 为输入生成 $r \in [0,1)$，避免 `Math.random()` 导致的不可复现。
- 提供全局 `SEED` 常量（默认 1337）；更换 SEED 即更换整局随机序列，便于「同一初始条件 → 同一结果」与调试/单测（满足 `DESIGN.md` R4）。

## 2. 单位与尺度约定（Units & Scale）

| 量 | 单位 | 约定值 | 说明 |
|---|---|---|---|
| 空间 | 格（cell） | 1 格 $\approx 6\ \text{mm}$ | 使 320 格宽 $\approx 1.92\ \text{m}$、180 格高 $\approx 1.08\ \text{m}$，桌面级沙盘尺度（近似） |
| 时间 | tick | $1\ \text{tick} = 1/60\ \text{s}$ | 固定步长 |
| 温度 | °C | `Float32`，$[-200, 2000]$ | 环境温度 $T_{amb} = 20$ |
| 密度 | kg/m³（相对） | 见 §4 | 仅用于位移比较（决定浮沉/沉浮/置换），不参与动力学积分 |
| 质量 | 归一化 | 每格质量 = 1（无量纲） | 「质量守恒」= 格数守恒（§13） |

| 时间率 | 每 tick 概率 $p \in [0,1]$ | 见 §7 | 反应/相变以每 tick 概率表达；平均耗时 $= 1/p$ tick |

## 5. 物态移动规则（Movement Rules）

> 通用前置：目标格可进入的条件 = 目标为 `EMPTY`，**或** 目标为可移动流体且密度更低（则**交换**两格）。静态固体（`movable=false`）永不被置换。
> 所有概率判定用确定性哈希（§1.5）。

### 5.1 粉末（Powder：SAND/SOIL/SALT/DUST/SNOW/ASH/GUNPOWDER/SEED）
按优先级尝试（命中即停）：

1. **正下方** `(x, y+1)`：若可进入 → **必然下落**（$p = 1.0$）。
2. **斜下方** `(x-1, y+1)` 与 `(x+1, y+1)`：先按哈希随机决定左右优先序，对每个可进入的斜格以概率

$$p_{\text{diag}} = \texttt{repose}$$

尝试移动。`repose` 越高越易滑动 → 堆越平；越低越陡。**休止角由 `repose` 涌现**，无需显式角度：
   - `SAND` repose 0.85 → 接近水平摊开
   - `SNOW` repose 0.35 / `DUST` 0.40 → 陡而松散的小堆
3. 粉末不主动上升。

**落速**：粉末每 tick 至多移动 1 格（无加速），保证可预测（支柱 1）。

### 5.2 液体（Liquid：WATER/OIL/LAVA/ACID/LN2/SPRING）
按优先级：

1. **正下方** 可进入 → $p = 1.0$ 下落。
2. **斜下方** 两个方向 → 各 $p = \texttt{mobility}$。
3. **水平** `(x±1, y)` → $p = \texttt{mobility} \times 0.8$（水平铺展/找平）。
4. **上浮**：若 **正下方**是密度更高的液体（如 OIL 在 WATER 下）→ 交换（浮力）。

**黏度** $= 1 - \texttt{mobility}$：`LAVA` mobility 0.35 → 缓慢黏稠；`WATER` 0.90 → 快速铺展。
**分层**：由密度差自然分层——`OIL(900)` 浮于 `WATER(1000)` 之上；`LAVA(2800)` 沉于水底；`LN2(807)` 浮于一切常液体之上。

### 5.3 气体（Gas：STEAM/SMOKE/FIRE/GAS）
按优先级：

1. **风力平流**（先于浮力，§11）：以 $p = \texttt{wind.strength} \times \texttt{windFactor}$ 沿风向移动 1 格。
2. **浮力上升** `(x, y-1)` 或斜上 → $p = \texttt{mobility}$（因所有气体密度 $< 1$，默认上升；密度越小的气越急）。
3. **随机扩散**：水平方向 `(x±1, y)` → $p = \texttt{mobility} \times 0.5$，方向由哈希定。
4. 气体遇顶边（$y=0$ 再向上）→ **从系统移除**（"vented"，§13.3）。

`FIRE` 特殊：除上述外，还会按 §9 点燃邻格燃料；上升更快（mobility 0.8）。

## 6. 热学模型（Thermal Model）

### 6.1 离散导热公式
对每个非 `EMPTY` 格 $i$，与其 4 邻域 $N(i)$ 交换热量。使用双缓冲 `nextTemp`：

$$T_i' = T_i + \alpha \sum_{j \in N(i)} \frac{k_i + k_j}{2}\,\bigl(T_j - T_i\bigr)$$

- $\alpha = \texttt{HEAT\_COUPLING} = \mathbf{0.005}$（全局热耦合系数）
- $k$ = 各元素 `conductivity`（§4.1）
- **稳定性约束**：单格单 tick 增益系数 $= \alpha \cdot 4 \cdot \max(k) = 0.005 \times 4 \times 0.9 = 0.018 \ll 0.5$，满足显式差分稳定条件，绝不振荡发散。
- **实现注记（每对只算一次）**：上式若对每格都遍历 4 邻域，每对会被算两遍（结果相同、开销翻倍）。实现时**只与右、下两个邻居交换**（$j \in \{E, S\}$）。

> ⚠️ **α 与空气 k 的联合标定（审查 F01 修正 · 致命级）**
> 首版取 $\alpha = 0.12$、空气 $k = 0.05$，则岩浆（1200 °C）与一个空气格的热交换高达 **−24.8 °C/tick**，
> 4 邻格合计 **−99 °C/tick** → **约 5 tick（0.08 秒）就把岩浆降到凝固点 700 °C**。岩浆根本来不及与任何东西交互，整个"岩浆玩法"直接失效。
> **同理，冰、液氮、火焰全部会瞬间失温。**
>
> 修正：$\alpha \to 0.005$，空气 $k \to 0.002$，使**空气成为近乎绝热的介质**
> （物理依据：空气导热系数 0.026 W/(m·K)，仅为水的 0.6 的 **1/23**；首版把空气设成 0.05 是水的 1/12，严重高估）。
>
> 标定后关键交互速率验证：
>
> | 交互 | 每 tick 温差变化 | 到目标耗时 |
> |---|---|---|
> | 岩浆 → 空气散热（3 个空气邻格） | ≈ −2.7 °C | 1200→700 °C：**≈ 2.2 s** ✅ |
> | 岩浆 加热 水 | ≈ +2.1 °C / 邻格 | 20→100 °C：**≈ 0.65 s** ✅（淬水剧烈，符合预期） |
> | 岩浆 加热 冰（−10 °C） | ≈ +1.8 °C / 邻格 | −10→0 °C：**≈ 0.6 s** ✅ |
> | 火焰 加热 木柴 | ≈ +1.2 °C / 邻格 | 22→300 °C：**≈ 3.7 s**（另有 §9 概率点火，不依赖此路径） |
> | 冰 在 20 °C 空气中 | ≈ +0.08 °C | −10→0 °C：**≈ 2.0 s** ✅ |

### 6.2 边界与空气
- 网格外视为**绝热**（无热流出去/进来），热交换仅在网格内。
- `EMPTY` 参与导热（$k=0.05$），使空气成为**弱导热介质**。

### 6.3 向环境温度弛豫（Cooling / Relaxation）
每次导热后，向 $T_{amb}=20$°C 弛豫：

$$T_i' \leftarrow T_i' + r_{c(e_i)} \cdot \bigl(T_{amb} - T_i'\bigr)$$

- $r_{c}$ 按类别取基础值：

| 类别 | `envRelax` 基础值 | 说明 |
|---|---|---|
| EMPTY（空气） | 0.10 | 强弛豫 → 空气是环境热库，让热量「散到空气里」 |
| gas | 0.004 | 气体较慢冷（原 0.02 会让蒸汽一冒出来就冷凝，见审查 F02） |
| liquid | 0.0005 | 液体极慢冷（原 0.005 会让岩浆在 0.7 s 内凝固） |
| solid/powder | 0.001 | 固体极慢冷 |

- **暴露加成**：若该格的 4 邻域中**至少一个为 `EMPTY`**，则 $r_{c} \leftarrow r_c \times \texttt{EXPOSED\_RELAX\_MULT}$，其中 `EXPOSED_RELAX_MULT = 2.0`。理由：裸露表面散热快于内部（近似）。

**效果示例（近似）**：一块 500 °C 的石头放入空气，暴露面按 $0.001 \times 2 = 0.002$ 弛豫，约需 $2.3/0.002 \approx 1150$ tick（**≈ 19 s**）回到室温附近；空气自身弛豫极快（约 10 tick 回 20 °C），不会自己累积热量。

### 6.4 相变潜热的近似处理（Latent Heat Approximation）——**近似**
真实相变需吸收/释放潜热（冰融化 $334\ \text{kJ/kg}$），本作**不引入第二温度变量**，改用**温度平台钳制（plateau clamp）法**近似：

- 当某格进入相变阈值区（如冰处于 $[0, +2]$°C 且判定将融化），将其温度**钳在相变点** $T_{pc}$，并累计内部进度 `latent++`；
- 若在平台期内被重新加热/冷却出阈值区，则 `latent` 按 $1$ tick 衰减，相变不发生；
- 仅当「平台停留累计」超过阈值 $\texttt{LATENT\_TICKS}$ 时，才真正切换物态，并把温度设为 $T_{pc}$。

| 相变 | 平台温 $T_{pc}$ | `LATENT_TICKS` | 说明 |
|---|---|---|---|
| ICE → WATER | 0°C | 12 | 融化需持续 12 tick 供给热量（近似潜热） |
| WATER → STEAM | 100°C | 8 | 沸腾需持续供热 |
| STEAM → WATER | 100°C | 6 | 冷凝放热 |
| LAVA → STONE | 700°C | 10 | 凝固释放潜热（近似） |
| SNOW → WATER | 0°C | 4 | 雪比冰更快融（近似，结构疏松） |
| LN2 → STEAM | -196°C | 6 | 气化吸热 |

> **近似理由**：格级仿真若严格追踪焓值需额外 `Float32` 场与更复杂的稳定性处理，收益低。平台法在视觉与手感上等价，且**完全确定、可编码**。所有相变点均在 §7 给概率，平台法只决定「切换时刻的能量门槛」。

**平台法与 §7 概率的关系（消除双重定义歧义 · 审查 F04）**
两者是**串联的两道闸**，不是二选一：

```
每 tick 判定某格是否相变：
  ① 能量闸：latent ≥ LATENT_TICKS ？
     · 处于阈值区（|T − T_pc| ≤ 2）时：温度被钳在 T_pc，latent++
     · 越过阈值但不在窗口内（如 200 °C 的水）：latent 每 tick +1（不再钳温、不再吸潜热 —— 近似）
     · 退回阈值另一侧：latent 每 tick −1（下限 0）
  ② 随机闸：rnd() < p(T) ？   ← p 见 §7
  ① 且 ② 同时通过 → 真正切换物态，latent 归零
```

- **窗口内钳温**是潜热的物理表达：格子在相变点"停留"而不升温，说明热量被用来改变物态而非提高温度。
- **窗口外不钳温**（如过热到 200 °C 的水）：直接按 §7 概率蒸发，不吸收潜热。这是**近似** —— 真实的水一旦超过沸点会剧烈闪蒸，本作以"概率随温度上升"来表达，视觉与手感等价。
- 由此，「水多久变汽」= `max(LATENT_TICKS_BOIL, 1/p)` tick，两段都可调。

## 7. 相变表 + 量化概率（Phase Transitions）

> 每格每 tick 以概率 $p$ 判定；平均耗时 $= 1/p$ tick $= 1/(60p)$ 秒。所有概率均与温度相关，曲线形状见说明。

### 7.1 水 → 蒸汽（WATER → STEAM）★核心
**分段概率**（`p` 为每 tick 概率）：

| 温度区间 | 公式 / 概率 | 说明 |
|---|---|---|
| $T < 60$°C | $p = 0$ | 不蒸发 |
| $60 \le T < 100$°C | $p = 0.0003\,(T-60)$，**仅当该格有 `EMPTY` 邻格（表面水）** | 缓慢表面蒸发：80°C→0.006，99°C→0.0117 |
| $T \ge 100$°C | $p = \min\bigl(0.50,\ 0.02 + 0.001\,(T-100)\bigr)$ | 沸腾，温度越高越快 |

**沸腾段数值表**：

| T (°C) | 100 | 120 | 150 | 200 | 300 | 400 | 500 | ≥600 |
|---|---|---|---|---|---|---|---|---|
| $p$/tick | 0.020 | 0.040 | 0.070 | 0.120 | 0.220 | 0.320 | 0.420 | 0.500 |
| 平均 tick | 50 | 25 | ~14 | ~8 | ~4.5 | ~3.1 | ~2.4 | 2 |
| 平均秒 | 0.83 | 0.42 | 0.24 | 0.14 | 0.076 | 0.052 | 0.040 | 0.033 |

**曲线形状说明**：$T<100$ 段近似为 0（仅在表面有微量蒸发），$T=100$ 处阶跃到 0.02，随后**线性增长**、在 $T\approx600$ 处封顶 0.5（每 tick 至少熬 2 tick 才蒸发）。即：**临界温度附近「犹豫」约 0.8 秒，温度越高驱逐越暴力**。该形状服务于支柱 1（玩家能学会「水要烧到 100°C 才开」），同时高温下足够迅猛。

### 7.2 蒸汽 → 水（STEAM → WATER，冷凝）
$$p_{cond}(T) = \operatorname{clamp}\bigl(0.00015\,(100 - T),\ 0,\ 0.02\bigr),\quad T < 100$$

| T (°C) | ≥100 | 90 | 60 | 20 |
|---|---|---|---|---|
| $p$/tick | 0 | 0.0015 | 0.006 | 0.012（封顶区） |
| 平均秒 | ∞ | 11.1 s | 2.8 s | 1.4 s |

**形状**：越冷越快冷凝；室温蒸汽约 1.4 s 变回水（形成「雨」），热蒸汽在热源附近可长时间存留。$T\ge100$ 恒不冷凝。

### 7.3 冰 ↔ 水（ICE ↔ WATER）
- **融化** ICE → WATER（$T \ge 0$）：$p = \operatorname{clamp}\bigl(0.05 + 0.005\,T,\ 0,\ 0.50\bigr)$
  | T | 0 | 10 | 20 | 50 | ≥90 |
  |---|---|---|---|---|---|
  | p | 0.05 | 0.10 | 0.15 | 0.30 | 0.50 |
- **凝固** WATER → ICE（$T \le -2$）：$p = \operatorname{clamp}\bigl(0.025\,(-T),\ 0,\ 0.40\bigr)$
  | T | -2 | -5 | -10 | -16 | ≤-16 |
  |---|---|---|---|---|---|
  | p | 0.05 | 0.125 | 0.25 | 0.40 | 0.40（封顶） |
- **迟滞（hysteresis）**：凝固阈值 $-2$ 与融化阈值 $0$ 之间形成 $[-2,0]$ 的**死区**，防止在 0°C 附近来回闪烁。

### 7.4 雪 → 水（SNOW → WATER，$T \ge 0$）
$p = \operatorname{clamp}\bigl(0.08 + 0.005\,T,\ 0,\ 0.50\bigr)$：0°C→0.08，20°C→0.18，≥84°C→0.50。雪比冰融得更快（结构疏松，近似）。

### 7.5 岩浆 → 石头（LAVA → STONE，$T \le 700$）
$p = \operatorname{clamp}\bigl(0.01\,(700 - T),\ 0.02,\ 0.50\bigr)$：700°C→0.02（缓慢，平均 50 tick），690°C→0.10，≤650°C→0.50。
**迟滞**：岩浆凝固于 700°C，而石头熔于 1200°C（§7.6），$[700,1200]$ 为死区，避免岩浆/石头抖动。

### 7.6 石头 → 岩浆（STONE → LAVA，$T \ge 1200$）
$p = \operatorname{clamp}\bigl(0.005\,(T-1200),\ 0,\ 0.30\bigr)$：1200°C→0，1300°C→0.30（封顶）。需要持续高温。

### 7.7 其他熔融（近似：统一熔为 LAVA）
| 元素 | 阈值 | $p$ | 说明 |
|---|---|---|---|
| GLASS → LAVA | $T \ge 1400$ | 0.02 | 玻璃熔融（近似归入岩浆） |
| METAL → LAVA | $T \ge 1500$ | 0.02 | 金属熔融（近似） |
| SALT → LAVA | $T \ge 801$ | 0.02 | 盐熔融（近似） |
| SAND → GLASS | $T \ge 1700$ | 0.03 | 沙烧结成玻璃（炼玻璃链） |

> **近似说明**：元素集只有一个「熔融态」（LAVA），故所有熔融统一映射为 LAVA；这是元素数量限制下的设计决策，物理上不精确但规则清晰。

### 7.8 液氮 → 蒸汽（LN2 → STEAM，$T \ge -196$）
$p = \operatorname{clamp}\bigl(0.0005\,(T+196),\ 0,\ 0.50\bigr)$：−196 °C → **0**（刚画下不蒸发），−150 °C→0.023，−100 °C→0.048，0 °C→0.098。
> **修正理由（审查 F09）**：首版为 `0.03 + 0.002(T+196)`，在 −196 °C 就已经有 $p=0.03$，
> **液氮一画到画布上 0.55 秒就全部汽化**，玩家根本来不及看到它冻结周围。
> 改为纯斜率式后，液氮必须先被环境加热才会汽化，实际寿命由 §6.3 的弛豫主导（约 7 s 升到 −100 °C）。
- **冷效应**：LN2 存在时其低温经导热（k=0.35）迅速抽走邻格热量（§6）。
- **近似/决策**：LN2 气化后映射为 `STEAM`（复用「蒸汽」作为泛用冷雾），**并非水蒸气**。理由：元素集无独立氮气，复用蒸汽可保留「可见的上升冷雾」且不新增元素。备选方案（Backlog）：LN2 → `EMPTY` + 一圈 $-120$°C 冷爆。

### 7.9 相变一览（速查）

| # | 相变 | 触发条件 | 概率公式 |
|---|---|---|---|
| P1 | WATER→STEAM | $T\ge100$ | $\min(0.5, 0.02+0.001(T-100))$ |
| P1b | WATER→STEAM | $60\le T<100$ 且表面 | $0.0003(T-60)$ |

## 9. 燃烧模型（Combustion Model）

### 9.1 点火三要素
一格燃料 $F$ 被点燃需**同时**满足：

1. **可燃**：`flammability > 0`；
2. **邻近火源**：4 邻域存在 `FIRE` 或 `LAVA`；
3. **有氧气**：4 邻域至少一格为 `EMPTY` / `GAS` / `STEAM`（用「存在空气格」近似氧气供给 —— **近似**，本作无独立氧元素）。

满足三条后，按 §9.2 的概率判定是否点燃。
**特例（自燃阈值）**：若该格自身温度 $T \ge$ `ignitionTemp`，则 $p_{ign} = 1.0$（已被烤到燃点，必燃）。

> 这样两个属性各有确定语义：`flammability` = **接触火焰时的引燃速度**；`ignitionTemp` = **自燃阈值**。
> 首版把"自温 ≥ ignitionTemp"混进条件 1，导致一张表里同时存在"必燃"与"按概率"两条互相冲突的路径（审查 F05），现已拆清。

### 9.2 点燃概率与火焰寿命
$$p_{ign} = \texttt{flammability} \times b_{dir}$$
- $b_{dir}$ 为方向偏置：**向上 1.5、水平 1.0、向下 0.6**。这产生「**火向上蔓延**」的观感——上方燃料更易被点燃，火焰整体上窜。
- 点火后：该格 `element = FIRE`，`temp = T_{burn}`（见 §8 表），`age = 0`。
- **火焰寿命**：`FIRE.lifetime = 40`，实际 $L = 40 \pm 10$（确定性哈希抖动），$L$ 耗尽后：`FIRE → SMOKE`（$p=0.5$）或 `EMPTY`（$p=0.5$）。
- **烟产量**：近似为「火焰消亡时 50% 概率留一格烟」。

### 9.3 燃料残余
| 燃料 | 烧尽后 | 概率 |
|---|---|---|
| WOOD | ASH | 0.6（否则 EMPTY） |
| COAL | ASH | 0.8 |
| PLANT | ASH | 0.3 |
| OIL | EMPTY | 1.0（液体燃尽无渣） |
| GUNPOWDER | SMOKE/EMPTY | 0.5 / 0.5 |

### 9.4 快燃 / 爆燃（GUNPOWDER、GAS）
- 点燃后**不表现为持续火焰**，而是「本格→FIRE」并立刻以 $p=0.8$ 向 8 邻域的其它同类 `GUNPOWDER`/`GAS` 传播点火（链式），造成快速蔓延火光——**近似爆炸的观感**，但仍是格级传播（非瞬时）。

### 9.5 爆炸（TNT）
- **触发**：TNT 格遇 `T>=180`、邻接 `FIRE`、或被另一次爆炸波及（`flags` 传播）。
- **半径**：$R_{TNT} = 6$ 格（切比雪夫距离）。
- **效果**：对半径内所有格——
  - 静态固体（除 WALL）：$p=1.0$ → `EMPTY` 或 `FIRE`（$p=0.5$ 各半）；WALL 免疫；
  - 可移动物质：$p=0.6$ → `FIRE`，$p=0.4$ → 被抛出（沿径向移动 1–3 格，近似冲量）；
  - 温度：半径内所有格 $+400$（钳制到 `MAX_TEMP`）；
  - 引爆半径内的其它 TNT/GUNPOWDER/GAS（链式，最多 `MAX_CHAIN = 8` 层）。
- **性能上限**：单 tick 爆炸处理格数上限 `MAX_EXPLOSION_CELLS = 2000`，超出则截断。

## 10. 生命 / 植物模型（Life & Plant Model）

### 10.1 种子发芽（SEED → PLANT）★核心问题 ③
每 tick 对每个 `SEED` 格评估**三条件**：

| 条件 | 判据 | 阈值 |
|---|---|---|
| **湿度 moisture** | Moore 邻域（8 格）内存在 `WATER` **或** `SOIL` | $\ge 1$ |
| **温度 temp** | 该格温度 | $5 \le T \le 40$°C |
| **暴露 exposure**（「光」的近似） | 正上方连续 2 格中至少一格是 `EMPTY` 或 `WATER` | 未被深埋 |

- **计时器**：三条件全满足时 `age++`；任一不满足时 `age = max(0, age - 2)`（衰减）。
- **发芽判定**：当 `age >= 90`（连续满足 $\ge 1.5\ \text{s}$）后，每 tick 以 $p_{germ} = 0.05$ 判定 → `SEED → PLANT`（平均再等 20 tick ≈ 0.33 s）。
- **极端温度**：$T > 60$ → 种子直接死亡（→ `ASH`，$p=0.5$ / `EMPTY`）；$T < -10$ → 死亡（→ `EMPTY`）。

> **关于「光」**：MVP **无光模型**，用「暴露度（上方有空气/水）」作为光的近似（设计决策，见 `DESIGN.md` R10）。若后续加光源元素（Backlog），把 exposure 条件替换为「上方/侧向存在光源格」。

### 10.2 植物生长（PLANT 蔓延）
- **向上生长**：若正上方为 `EMPTY` 或 `WATER`，且该植物柱高度 $<$ `MAX_PLANT_HEIGHT = 40`，则 $p = 0.02$ 在正上方生成 `PLANT`。
- **向水蔓延**：若水平邻格为 `WATER` 且其上方为 `EMPTY`，则 $p = 0.01$ 生成 `PLANT`。
- **生长需湿度**：若 2 格半径内无水/土壤持续 `PLANT_WILT_TICKS = 300`，植物**枯萎** → `DUST`（$p=0.5$ / `EMPTY`）。
- **生命上限**：PLANT 无硬寿命，但可燃（§9）与被病毒感染（R15）。

### 10.3 病毒（VIRUS）
- 感染：见 R15 / R16。病毒自身不移动（`movable=false`），靠 PLANT/WOOD 结构扩散。病毒可燃（ignitionTemp 300）。

## 11. 气流 / 风场模型（Airflow & Wind）★核心问题 ④

### 11.1 风场定义
全局风向量 $\vec{w} = (w_x, w_y)$ 与强度 $\sigma \in [0, 1]$：

$$w_x = \sigma \cos\theta,\qquad w_y = \sigma \sin\theta$$

- $\theta$ 为风向角；$\sigma$ = 强度（玩家滑杆 `WIND.MAX_STRENGTH = 1.0`）。默认 $\vec{w} = (0,0)$（无风）。

### 11.2 平流（Advection）
每 tick 对每个 `gas` 格：以概率

$$p_{adv} = \sigma \times \texttt{windFactor}$$

沿 $(\operatorname{sign} w_x, \operatorname{sign} w_y)$ 方向尝试移动 1 格。方向按八向离散化。

- `STEAM / SMOKE / GAS` 的 `windFactor = 1.0` → 满强度风即 $p_{adv}=1.0$，随风流线飘散。
- `FIRE` 的 `windFactor = 0.5` → 火焰被吹偏（但不被直接吹灭，仍受 R1 制约）。
- 轻质粉末（`SNOW 0.4 / DUST 0.3 / ASH 0.3 / SEED 0.2`）**仅在其正下方为 `EMPTY` 时**（即处于空中）受风漂移。

### 11.3 热对流（Convection）——**近似**
- 本作已让**所有气体默认上升**（§5.3）。
- 额外近似：任一 `EMPTY` 格若 $T > 200$°C，视为「热空气柱」，使**其正上方气体**额外获得 $p=0.3$ 的上升推力，形成热源上方的强对流。

### 11.4 玩家风工具
- 在画布上拖拽定义 $\theta$（起点→终点方向）与 $\sigma$（拖拽长度归一化，或滑杆设定）。
- 八向罗盘按钮提供快捷方向；`Reset Wind` 置 $\vec{w}=0$。风一经设定即**全局持续生效**，直到下次修改。

### 11.5 风的可见性
- 画布边缘渲染淡色箭头（不遮挡内容），指示当前风向与相对强度（对齐 `ART.md` §1「界面隐形」）。

## 12. 用户四问 · 量化结论（Direct Answers）

### ① 水火关系是什么？
- **水灭火**：`FIRE` 与 `WATER` 相邻 → 火 $p=1.0$ 立即变为 `SMOKE`；同时水吸热 $+55$°C（R1）。
- **火煮水**：火的热量经导热（§6，水的比热 4186 最大、升温慢）使水升温；达到 **100°C** 后按 §7.1 概率蒸发。
- **水拦火势**：水的高比热 + 高导热 + 环境弛豫，使水成为**天然防火墙**——火焰无法穿过水体蔓延（火在 `WATER` 邻格即灭）。
- **岩浆遇水**：$p=1.0$ 岩浆变石头、水 $p=0.8$ 变蒸汽（R12）——最剧烈的「水火」交互。
- 一句话：**火在水面前必然熄灭，但会用水的升温换来一片蒸汽**。

### ② 水多久变蒸汽？与温度的关系？
见 §7.1。核心数值：
- **$<60$°C**：不蒸发。
- **$60$–$99$°C**：仅表面水微弱蒸发，$p=0.0003(T-60)$（80°C 时平均约 2.8 s）。
- **$100$°C**：$p=0.02$ → **平均 50 tick ≈ 0.83 秒**开始明显沸腾。
- **$200$°C**：$p=0.12$ → **≈0.14 秒**。
- **$500$°C+**：$p=0.42\sim0.5$ → **≈0.03–0.04 秒**（近乎瞬间汽化）。
- 关系：**温度越高，蒸发概率近似线性增长、在 600°C 附近封顶 0.5/tick**——「100°C 附近会犹豫近 1 秒，越热越快、最快每 2 tick 走一格」。

### ③ 植物发芽条件是什么？
见 §10.1。需**同时**满足三条件并累积 90 tick：
1. **湿度**：8 邻域内 $\ge 1$ 个 `WATER` 或 `SOIL`；
2. **温度**：$5 \le T \le 40$°C（$>60$ 死，$<-10$ 死）；
3. **暴露（近似「光」）**：正上方 2 格内有 `EMPTY` 或 `WATER`（未深埋）。
满足后连续 90 tick（1.5 s），再以 $p=0.05$ 每 tick 判定发芽。**结论：给种子一点水、保持在室温、别把它埋死，约 1.8 秒后发芽。**

### ④ 气流因素如何起作用？
见 §11。四个层面：
1. **全局风**：$\vec{w}=(\sigma\cos\theta, \sigma\sin\theta)$，玩家可设方向与强度 $0\!-\!1$。
2. **气体平流**：蒸汽/烟/瓦斯以 $p=\sigma \times 1.0$ 沿风移动；火以 $0.5$ 被吹偏。
3. **轻质粉末漂移**：雪/尘/灰/种子在空中（下方为 `EMPTY`）时按 `windFactor` 随风飘。
4. **热对流**：气体本身上升（浮力），热源（$>200$°C 的空气柱）额外给上方气体 $p=0.3$ 上推，形成向上烟柱。

## 13. 守恒与不变量（Conservation & Invariants）

### 13.1 质量守恒
- **定义**：本作「质量」= 非 `EMPTY` 的格数（每格质量归 1）。
- **移动守恒**：所有移动均为**交换/搬移**（A 与 B 交换，或 A→空位），格数不变。
- **相变守恒**：1 格 → 1 格（水↔汽、冰↔水、岩浆↔石），格数不变。
- **气体逸出**：气体上升到顶边被移除（§13.3），这是**唯一合法的「质量离开系统」途径**（相当于排放到太空）。

### 13.2 质量创生例外（必须写明规则）
允许**创生**的元素仅两个，均受配额约束：

| 元素 | 规则 | 约束 |
|---|---|---|
| **CLONE 克隆体** | 每 `CLONE_COPY_INTERVAL = 4` tick，把 8 邻域中**一个**非静态元素复制到 `CLONE` 旁的一个 `EMPTY` 格 | 全局 `MAX_CLONE_CELLS = 2000`；达到后 CLONE 停止复制 |
| **SPRING 水源泉** | 每 `SPRING_EMIT_INTERVAL = 6` tick，向一个相邻 `EMPTY` 格生成 `WATER` | 全局 `MAX_SPRING_CELLS = 1500`；达到后 SPRING 停喷 |

> 这两个是「无限资源」的**有意设计**（`DESIGN.md` 支柱 2 涌现玩法），但配额防止画面爆炸与性能崩溃。

### 13.3 系统边界
- 气体到达 $y=0$ 再向上 → 移除（`element = EMPTY`，温度不保留）。
- 其它三边（左/右/下）为**实心墙**：粉末/液体在边缘堆积，不越界。

### 13.4 温度不变量
- 每 tick 结束钳制：$T \leftarrow \max(\texttt{MIN\_TEMP}, \min(\texttt{MAX\_TEMP}, T))$，`MIN_TEMP=-200`，`MAX_TEMP=2000`。
- ⚠️ **温度场必须用浮点存储**（`Float32Array`），**不得用 `Int16Array`**。理由见审查 F15：
  冰在空气中每 tick 只升温 0.083 °C；若存成整数 °C 并在回写时取整，这 0.083 会被**每 tick 永久丢弃**，
  冰将永不停在 −10 °C 而不融化（实测 3000 tick 毫无变化）。这正是"精度取舍必须双向验算"的典型案例。
  内存代价：320×180×4 B = 230 KB，相对可忽略。

## 15. 边界与失败模式（Boundaries & Failure Modes）

### 15.1 网格边界行为
| 边 | 行为 |
|---|---|
| 底（y = H-1） | **实心地面**：粉末/液体堆积；不可穿过 |
| 左/右（x = 0 / W-1） | **实心侧壁**：流体贴壁停止；不环绕 |
| 顶（y = 0） | **排气口**：气体继续向上即被移除（§13.3） |

### 15.2 数量上限
- 全网格最多 57,600 格；`MAX_CLONE_CELLS`/`MAX_SPRING_CELLS` 分别为 2000/1500。
- 达到配额时：克隆体/源泉**静默停摆**（不报错、不刷屏），画面保持稳定。

### 15.3 极端温度
- 全局钳制 $[-200, 2000]$°C（§13.4）。爆炸叠加的 $+400$ 会命中上限并被钳住。液氮的 $-196$ 不触及下限，仍有冷却余量。

### 15.4 多反应同时命中的优先级仲裁
同一格一帧内命合多条件时，按**固定优先级**只执行最高者（用 `flags.bit1` 落锁）：

```
1. 爆炸（TNT / 链式）            ← 最高
2. 灭火（FIRE + WATER）
3. 燃烧（点燃燃料）
4. 腐蚀（ACID）
5. 溶解（SALT + WATER）
6. 克隆 / 病毒（复制类）
7. 相变（thermalPass / phasePass）
8. 常规移动
```
理由：破坏性/剧烈事件优先，避免「一帧内先被水灭又被点燃」的矛盾态。

### 15.5 已知失败模式与对策
| 失败模式 | 症状 | 对策 |
|---|---|---|
| 液体单侧漂移 | 所有水往一边挤 | §1.4 扫描方向逐帧交替 |
| 粒子穿越/双跳 | 一格一帧移动多格 | §1.4「已移动」标记 |
| 0°C 附近闪烁 | 水冰/水汽反复切换 | §7.3/§7.5 迟滞死区 |
| 沸腾概率过高 | 水入火即秒变汽，无法灭火 | `WATER.EVAP_P_AT_100` 可调，默认 0.02 保守 |
| 克隆/源泉刷爆画面 | 格数爆炸、掉帧 | §13.2 配额上限 |
| 爆炸递归卡死 | TNT 链无限递归 | `TNT.CHAIN_MAX` + `MAX_EXPLOSION_CELLS` |
| 热传导发散 | 温度振荡/NaN | §6.1 稳定性约束 α·4·k<0.5 |
| 蒸汽迅速消失 | 看不到上升烟柱 | §7.2 冷凝系数已压低（室温 ~1.4 s） |
| 不可复现 | 同操作不同结果 | §1.5 确定性哈希 + 固定 SEED |

### A.1 关键耦合系数（改这几个就能显著改变手感）

| 键 | 值 | 调大后的效果 | 调小后的效果 |
|---|---|---|---|
| `PHYS.HEAT_COUPLING` α | **0.005** | 一切变快：岩浆秒凝、冰秒化 | 温度几乎不传导，相变只能靠反应直接触发 |
| `ENV_RELAX_EMPTY` | 0.10 | 空气更快吸走热量 | 热量在空气里堆积成"热浪" |
| `ENV_RELAX_GAS` | 0.004 | 蒸汽更快冷凝成雨 | 蒸汽长时间漂浮，画面发白 |
| `ENV_RELAX_LIQUID` | 0.0005 | 岩浆更快凝固 | 岩浆长时间保持，毁掉一切 |
| `ENV_RELAX_SOLID` | 0.001 | 热石头/冰更快回到室温 | 保温性好，适合做"暖床" |
| `WATER.EVAP_P_AT_100` | 0.02 | 水一开就冲走，灭火变难 | 水更难蒸发，沸腾几乎看不见 |

### A.3 三个最容易写错的实现点

1. **导热每对只算一次** —— 只与东、南邻居交换，否则开销翻倍（§6.1）。
2. **移动时温度必须跟着元素走** —— 只换元素不换温度，会让热沙穿过冷水后自己变凉（§4.5）。
3. **爆炸物走引信，不走普通燃烧** —— 炸药被点燃后不能被 §9.3 的火焰规则接管，否则它会在引信期间到处乱飘（§8.3）。
