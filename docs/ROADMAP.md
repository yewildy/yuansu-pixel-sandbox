# ROADMAP — 元素像素游戏

> 主理人口径的公开路线图。已完成项打勾，未完成项按价值排序。

## v1.0（已完成 · 2026-09-30）

- [x] 落沙引擎：粉末 / 液体 / 气体三态移动
- [x] 温度场：离散导热、环境弛豫、潜热平台
- [x] 相变：蒸发 / 冷凝 / 结冰 / 融化 / 熔融 / 汽化
- [x] 燃烧：火焰向上蔓延、燃料残余、缺氧熄灭
- [x] 爆炸：火药 / 瓦斯 / TNT 的引信与连锁
- [x] 生态：种子发芽、植物生长、枯萎、病毒感染
- [x] 风场：全局风向与热对流
- [x] 30 种元素
- [x] 中文 / English / 日本語
- [x] 存档、读档、PNG 导出
- [x] 元素的图鉴与规则速查
- [x] 音盲友好纹样与高对比模式
