# ACCESSIBILITY — 无障碍设计说明

| 字段 | 值 |
|---|---|
| 版本 | v1.0.0 |
| 关联 | `docs/ART.md` §4 · `docs/DESIGN.md` §8.4 |

## 1. 为什么这个游戏需要无障碍

本作是**纯视觉编码的模拟**：一个格子长什么样，玩家就要判断它是什么元素。如果只用颜色区分，色盲玩家会失去一半信息量。所以无障碍在这里不是"加分项"，而是**可玩性的前提**。

## 2. 色彩之外的冗余编码

### 2.1 明度优先

所有易混色组（水 / 液氮 / 冰、岩浆 / 火 / TNT、烟 / 尘 / 灰）**同时用色相与明度两个维度**区分。红绿色盲与蓝黄色盲都能靠明暗分辨。

### 2.2 纹样编码（可选开关）

| 元素 | 纹样 |
|---|---|
| 液氮 | 水平虚线（霜纹） |
| 强酸 | 动态斑点（蚀刻感） |
| 冰 | 十字结晶纹 |
| 木材 | 竖向纹理 |
| 炸药 | 横向亮带 |
| 玻璃 | 对角反光暗角 |

开关名称：**色盲友好纹样**。默认关闭，随高对比模式自动开启。

### 2.3 动效作为第三编码

气体在动、固体不动；岩浆缓慢流动、火焰高频闪烁。**运动本身就是信息**，不依赖颜色。

## 3. 高对比模式

- 提高元素色与画布底的对比度（画布底进一步压暗）；
- 元素轮廓加一圈 1px 描边；
- UI 文字对比度提升到 ≥ 7:1。

## 4. 动效与光敏安全

- `prefers-reduced-motion: reduce` 时：关闭所有发光脉冲、关闭火焰高频闪烁、元素抖动的时间项恒为 0。
- **任何闪烁频率上限 5 Hz**，禁止每帧闪烁（防光敏性癫痫）。

## 5. 键盘可达性

| 按键 | 功能 |
|---|---|
| `Tab` / `Shift+Tab` | 在工具栏、元素面板、控制条之间移动焦点 |
| `Enter` / `Space` | 激活当前控件 |
| `空格` | 全局暂停 / 继续（焦点不在按钮上时） |
| `1`–`9` | 快速选择常用元素 |
| `Esc` | 关闭帮助 / 图鉴面板 |

焦点环统一使用 `#7CC8FF`（`ART.md` §3 `focusRing`），保证在任何底色上都可见。

## 6. 触控与点击尺寸

- 所有可点击目标最小 **44 × 44 px**（对齐 WCAG 2.5.5）。
- 触屏下画布 `touch-action: none`，避免误触发页面滚动。
- 触屏画笔最小半径 2，长按可连续绘制。

## 7. 字号与可读性

- UI 基础字号 ≥ 13px，正文 ≥ 14px。
- 中 / 英 / 日 统一使用系统字体栈回退（`ART.md` §5.1），不依赖网络字体，避免加载失败导致方框。
- 不使用纯白文字（`#E6EAF2` 替代），降低长时间注视疲劳。

## 8. 已知不足

- 尚无屏幕阅读器专用描述（画布本质是像素矩阵，需要额外的"区域摘要"朗读文本）。
- 无音效，因此没有音频层面的无障碍考量（也未引入听觉干扰）。
- 帮助文档只覆盖中文与英文，日文帮助内容较简。
