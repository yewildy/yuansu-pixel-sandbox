# 冷凝模型（v1.2.0）— 蒸汽 → 水

> 唯一真源：`src/core/transitions.js`（case 23 STEAM）+ `src/core/balance.js::STEAM`。
> 上游：本文档是 `docs/PHYSICS.md §7.2` 的**替换件**，冲突时以本文为准。
> 参照：Powder Game（DAN-BALL）—— 它的 STEAM 根本不变水，变水的是 CLOUD，且必须**碰到 block/固体**才触发。

---

## 1. 问题：v1.1 的蒸汽「一秒变雨」

用户实测原话：

> 水蒸气受冷过程是不是太快了，立刻就会变成水滴下来非常不合理。

v1.1 的规则只有一条：`T < 100` 就按 `p = COND_COEF·(100 − T)` 凝结。配合 `ENV_RELAX_GAS = 0.004`，
蒸汽离开水面后被空气以**每秒约 21%** 的速率吹冷（半衰期约 3 tick），
于是整片蒸汽在 1 秒内全部变成水砸下来 —— 观感是「开水冒雨」而不是「开水冒汽」。

两条成因缺一不可：

| 成因 | 数值 | 后果 |
|---|---|---|
| 气体散热过快 | `ENV_RELAX_GAS = 0.004`（暴露 ×2 → 0.008/tick） | 蒸汽 3 tick 就被吹到室温 |
| 冷凝无成核条件 | 只看自身温度 | 悬在半空的蒸汽也会成水，直接变成雨 |

---

## 2. 修复一：气体散热速率

```
PHYS.ENV_RELAX_GAS:  0.004  →  0.0006
```

理由：空气本身是热的不良导体（k≈0.026），悬浮在空气中的蒸汽团没有理由几帧就被吹到室温。
改后半衰期约 1150 tick（≈19 s），蒸汽可以正常上升、飘散、或被顶部热沉处理。

---

## 3. 修复二：接触成核（非均相成核）

### 3.1 物理依据

现实中的水蒸气凝结绝大多数是**非均相**的 —— 需要凝结核（尘粒、器壁、液膜）。
在纯净空气中，均相成核需要极大的过饱和度，速率要低好几个数量级。
宏观表现就是：**水蒸气可以在空气中飘很久，但一碰到冷玻璃/锅盖就立刻结出水珠。**

Powder Game 用了一个等价的离散做法：STEAM 不会变水；独立元素 CLOUD 变水，
且触发条件是「碰到 block 和 solid 元素」（玻璃、带电玻璃、冰、克隆体、金属除外；碰冰变雪、碰金属变雷）。

### 3.2 实现

`transitions.js::hasColdNucleus(grid, i)`：4 邻域存在**非气体元素**（`state !== 'gas'`）
且其温度 `< STEAM.NUCLEUS_COLD_T (95 ℃)` → 判为冷核。

```
p = clamp(COND_COEF · (100 − T), 0, COND_P_MAX)
if (!hasColdNucleus(i)) p *= STEAM.HOMO_F      // 0.2：均相成核折扣
```

- `NUCLEUS_COLD_T = 95 ℃`：**热水面不算冷核**，否则水一沸腾、上方的蒸汽立刻被自己凝回去，水永远烧不开；
- `LATENT_TICKS_COND: 6 → 24`：潜热平台，给蒸汽一段必须「放热」的时间（0.4 s）；
- 仍保留 `T ≥ 100` 恒不冷凝的硬闸（§7.2）。

### 3.3 参数

| 参数 | v1.1 | v1.2.0 | 含义 |
|---|---|---|---|
| `STEAM.COND_COEF` | 0.00015 | 0.00015 | **有冷核时**的凝结系数（T=20 ℃ → p≈0.012，半衰期约 1 s） |
| `STEAM.HOMO_F` | — | **0.2** | 无冷核折扣（等效 0.00003，半衰期约 5 s） |
| `STEAM.NUCLEUS_COLD_T` | — | **95 ℃** | 冷核温度上限 |
| `PHYS.LATENT_TICKS_COND` | 6 | **24** | 冷凝潜热平台 |
| `PHYS.ENV_RELAX_GAS` | 0.004 | **0.0006** | 气体散热速率 |

---

## 5. 玩家可见的现象（预期）

- 烧水 → 蒸汽柱上升 → 在半空**保持气态**、逐渐变淡 → 碰到冷的锅盖/天花板才在**顶壁结出水珠**并沿壁滑落；
- 冰面附近的蒸汽 → 凝成**雪**（由 ICE 的既有规则处理）；
- 蒸汽若一路升到画面顶部 → 从顶部逸出（§13.3 vent），不会积在天上。
