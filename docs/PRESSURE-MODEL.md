# 压强系统（Pressure Model）· v1.6.1

> 真源文档 · 关联：`src/core/pressure.js`（实现）、`src/core/balance.js`（`PRESSURE` 组）、
> `src/core/grid.js`（`press` / `stress` / `yieldStamp`）、`src/core/engine.js`（步 2b）、
> `src/core/reactions.js`（爆炸冲压）、`tests/run.js`（V28–V31）、`docs/PHYSICS-AIR.md` 附录 I。

用户原话：

> 「我希望可以加入压强系统，比如我金属绕了一个圈，圈内圈外压强不一样会容易按照压强慢慢变形成圆形之类的
> （记住这个慢慢，因为现实世界里是比如先变一个最脆弱的地方突出或破掉…），总之就是要按现实物理规则（不过是 2d 的）。
> 还有空气流动也可以做成因为压强的变化所以才变化的等等，就是联动。（水的压强不用模拟，因为太大了，基本上都是 1，不太好压缩。）」

---

## 0. 三条设计约定

1. **水的压强不模拟**（用户明确要求）。2D CA 里水的体积模量 ~2.2 GPa，"基本都≈1"，模拟它只会带来无谓抖动。
   **一切液体 / 粉末都不进压强场** —— 只有 `state==='gas'` 的气体（含 AIR）与 `state==='solid' && !movable`
   的固体墙参与。
2. **热压按理想气体关系即时算**（查理定律：体积固定时 P ∝ T）：
   `P_i = P0 · (T_i + 273) / (T_amb + 273) + press[i]`
   环境温气体 → `P = P0`；被加热的气体 → `P > P0`。**热压不落在 `press[]` 数组里**，
   每 tick 由温度场即时算出（"用温度现算"，不序列化、不守恒）。`press[]` 只存**冲击压/表压**
   （爆炸注入等，见 §2）。`P0 = 1.0` 是**基准表压**（环境温气体的总压基准），不是 1 atm 的绝对压强。
3. **压强只作用于"气体 ↔ 固体墙"界面**：气体之间发生压强驱动的置换；固体墙因跨壁压差累积应力而变形/屈服。

## 1. 热压（Thermal Pressure）

| 项 | 式 |
|---|---|
| 总压 | `P_i = P0·(T_i+273)/(amb+273) + press[i]` |
| 环境温气体 | `P = P0 = 1.0` |
| 500 °C 气体 | `P ≈ 1·(773/293) ≈ 2.64` |

热压差是"空气流动的联动"驱动力之一，也是金属盒被烤热后内壁受压的来源。见 §3。

### 1.1 密闭腔内部总压：先升后饱和于 ≈4.0（**不是**单调递增）

对**密闭**金属腔（内部若干 EMBER 持续加热）直接测内部气体总压 `P = P0·(T+273)/(amb+273)`
（数据来源：独立验证 `_qa_f3.js` F3-C）：

| 时刻 | 内部最高温 | 内部总压 |
|---|---|---|
| t≈0 | 20 °C | 1.000 |
| t≈500 | ≈882 °C | 3.942 |
| t≈4000 | ≈890 °C | 3.979（±0.02 抖动） |

- 内部总压随时间**先升后饱和**于 ≈4.0，**不是**严格单调递增（有 ±0.02 抖动）。
- **饱和原因**：加热源（EMBER）把内部气体温度钉在 ≈890 °C 上限，**温度场自身达到稳态**；
  而热压是温度的即时函数（`P = P0·(T+273)/(amb+273)`），温度不再上升 ⇒ 压强不再上升。
- ⚠ **不要用 `grid.press[]` 观察密闭加热场景的"压强曲线"**：`press[]` **只存冲击压/表压**，
  纯加热场景恒为 **0.000**。要看内部压强请用 `temp`（温度）或即时算出的总压
  `P = P0·(T+273)/(amb+273)`。

## 2. 冲击压（Impulse Pressure）

| 项 | 值 / 说明 |
|---|---|
| 字段 | `grid.press: Float32Array`（**不入存档**） |
| 注入 | `Pressure.impulse(grid, cx, cy, r, power)`：半径 r 内**气体格** `press += power·(1 − dist/r)`，dist 取**欧氏距离**（冲击压圆对称衰减） |
| 爆炸注入 | `explosionPass` 每个爆炸中心处理完半径格后调用，`r = TNT.RADIUS × IMPULSE_RADIUS_MULT(=2.5) = 25`、`power = TNT_IMPULSE = 2.5` |
| 衰减 | 每 tick `press *= IMPULSE_DECAY(=0.985)`（半衰期 ≈ 46 tick） |
| 平流 | 压强驱动置换时，`press` **随气体一起交换**（冲击波前向外传播） |

> **`press[]` 只装冲击压/表压**：纯加热（无爆炸注入）场景下全场 `press ≡ 0.000`，
> 内部压强完全来自热压（即时算、不落数组）—— 观察密闭加热请用 `temp` 或即时总压（见 §1.1）。

> **为什么冲压半径（25）比破坏半径（10）大**：实测破坏半径内冲击压走不出去 —— 半径内热气体被
> `airPass` 的浮力每 tick 先行搬走（`moveStamp` 落锁 → 压强步无法再动它），半径外又恒为 0，
> 导致压强无法平流到 12–25 格。物理上冲击波（压力扰动）本就比破坏半径传播得远，故取 2.5 倍。

## 3. 压差驱动气流（Pressure-driven Flow，联动核心）

`ctx` 中 tick 的 **2b 步**（`airPass` 之后、`reactionPass` 之前）：

1. 遍历气体格（含 AIR）；跳过：已移动过（`moveStamp===tick`）、**FIRE**（火焰是持续放热的反应前沿，
   不当作被动气团）、全环境温且无冲压者（等压惰性跳过 → 空画布近似零成本）。
2. 找 4 邻中**总压最小且为气体**的邻居 j；`ΔP = P_i − P_j`。
3. 过阈值则以 `p = min(1, ΔP × FLOW_K)` 交换（`grid.swap` + `moveStamp` 双边置 tick + `flowDir` 双边置方向位）。

**两套阈值**：

| 驱动源 | 阈值 | 附加条件 |
|---|---|---|
| **冲击压**（任一侧 `press≠0`） | `FLOW_EPS_IMPULSE = 0.02` | 无（冲击波必须顺畅外传） |
| **纯热压** | `FLOW_EPS = 0.5`（≈147 °C 温差） | **仅"垂直被堵"**（上方邻格是固体 / y=0）时驱动 |

> **为什么纯热压要收紧 + 加"垂直被堵"门**：开阔处的热对流已由既有 `airPass` 负责，若这里再叠加
> 一次热压流动，会把已标定的"热空气贴着热源上升/加热"手感冲掉（实测 A1 热空气回归：直接上方空气
> 60 tick 由 603 °C 掉到 26 °C）。被堵住的地方才是压强真正积累、必须靠"压强→流动"把气体挤出去的
> 地方 —— 也正是"密闭盒 + 缺口"（V30）和爆炸（V29）的情形。FLOW_EPS 由原稿 0.02 上调到 0.5，
> 同样是为了不打扰日常热对流。

## 4. 墙体应力 / 变形（Stress & Deformation）——"慢慢"的关键

候选 = `state==='solid' && !movable` 的格（WALL / STONE / GLASS / METAL / ICE / WOOD / COAL / TNT …）。

1. 收集 4 邻**气体总压**：`pmin` / `pmax` / 支撑数（非气体邻数）。
   - `支撑数 < 1`（四邻皆气体的孤立块）→ **跳过**（不是"墙"；否则阈值 = hardness×YIELD_K×(0/4)=0 → 任何热块瞬间破碎，A1 回归）。
2. **跨壁压差** `ΔP = pmax − min(pmin, P0)`：
   - `ΔP > DEFORM_MIN_DP` → `stress[i] += (ΔP − DEFORM_MIN_DP) × STRESS_RATE`。
   - **向大气敞开的一侧以环境基准 P0 为参考**（而非局部 `pmin`）：金属导热系数 k=8（为修"金属锅要传热"而设）
     会把外壁空气也烤到数百 °C，局部 `pmax≈pmin` → 金属盒**永不变形**。物理上开放世界的外侧压强由大气库
     决定，不因局部被烤热而抬高。于是只要有一侧接大气，压差就还原为"封闭侧表压"。
3. **屈服阈值** `thr = hardness × YIELD_K × (支撑数/4)`；脆性 `× BRITTLE_K`；**角部 `× CORNER_K`**；
   `IMMUNE`（WALL/CLONE/VIRUS/EMBER）直接跳过。
   - **角部应力集中**（`CORNER_K`）：某格有两个**互相垂直**的固体邻格（左上/上右/右下/下左）即视为角部。
     物理依据：受压方腔在直角处应力集中（这正是压力容器/舷窗都倒圆角的理由）→ 角部先屈服，
     对应"先在某个地方突出或破掉"。
4. 冷却已过（`yieldStamp[i] < tick − YIELD_COOLDOWN`）且 `stress > thr` → **屈服**：
   - **韧性（`DUCTILE: ['METAL']`）**：与总压最小的相邻气体格交换 → 墙向低压侧**蠕动**（突出/外扩），
     气体补位 → 环体扩张、趋于圆形。材料把应力带到新位（`×0.4` 松弛）。
   - **脆性（默认）**：`element = AIR`（破裂）；`stress = 0`。
     ⚠ 2D CA 近似：破裂后的物质守恒让位于游戏性（同 Powder Game 炸弹把玻璃变粉末的处理）。

## 5. 参数表（`Balance.PRESSURE`）

| 键 | 值 | 范围 | 说明 |
|---|---|---|---|
| `ENABLE` | true | — | 总开关（V30 对照用） |
| `P0` | 1.0 | >0 | **基准表压**（环境温气体总压 = 1.0；非 1 atm 绝对压） |
| `IMPULSE_DECAY` | 0.985 | 0–1 | 冲击压每 tick 衰减（半衰期≈46 tick） |

| `DEFORM_MIN_DP` | 0.15 | ≥0 | 起积应力的最小跨壁压差 |
| `YIELD_K` | 0.5 | >0 | 屈服阈值 = hardness × YIELD_K × (支撑数/4) |
| `BRITTLE_K` | 0.6 | 0–1 | 脆性阈值附加系数（玻璃比金属更早破裂） |
| `CORNER_K` | 0.4 | 0–1 | 角部应力集中系数（v1.6.1 新增） |
| `YIELD_COOLDOWN` | 40 | ≥0 | 屈服后冷却 tick |
| `DUCTILE` | `['METAL']` | — | 韧性（向低压侧蠕动，不变 AIR） |

| `TNT_IMPULSE` | 2.5 | ≥0 | 爆炸冲压强度（中心峰值） |
| `IMPULSE_RADIUS_MULT` | 2.5 | ≥0 | 冲压半径 = TNT.RADIUS × 该值 |

## 6. 为什么水不模拟（用户明确）

- 水的体积模量 ~2.2 GPa，1 atm 的压强波动下密度变化 ~10⁻⁵ —— 2D 网格上"水的压强基本都=1"，
  模拟它只会带来无谓的逐格抖动与性能开销。
- 本作的水由**不可压缩的液体移动规则**（密度序 + 找平 + 连通器）表达"静水压"的宏观结果（水往低处流、
  水面找平），不需要额外压强场。故 `WATER`（及一切液体/粉末）不参与 `pressurePass`。

## 7. 2D CA 近似与已知偏差（如实记录）

- **脆性破碎不守恒**：破裂 → 直接变 AIR，质量账本 +0（物质守恒让位于游戏性）。
- **韧性蠕动是"离散细胞"而非连续形变**：墙格一次外移一格；受 `YIELD_COOLDOWN=40` 节流 →
  宏观表现为"慢慢外扩/变圆"，但微观是格点跳变。
- **跨壁压差用 `min(pmin, P0)` 作低压参考**（而非局部 `pmin`）：近似"开放大气"边界，避免金属漏热
  把外壁空气烤热而抵消压差；**密闭热腔**（两侧都在封闭空间）会被**高估** ΔP（罕见，未处理）。
- **热压即时算、不守恒**：气体的"热压"不是被搬走的守恒量，而是每 tick 从温度场重算；真正的守恒量
  只有冲击压 `press`（且它每 tick 衰减）。
- **未做**：真正的压力求解（Poisson/NS）、声速、冲击波反射/折射、液体压强、湿度场。

## 9. 性能

`pressurePass` 每 tick 执行的额外成本：

- 等压惰性跳过（§3）：全环境温、无冲压的气体不发起流动 → **空画布近似零成本**；
- 步 3 只遍历固体墙格；
- 步 2 只在（温度偏离环境或带冲压）的气体格上做 4 邻比较。

**不改变 95% 填充场景的总预算**（实测见 `_diag_p2flow.js`：仿真 ≈11.7 ms/tick 已含"压差流动仅在被驱动格上有工作"，渲染 ≈1.8 ms，合计 ≈13.5 ms ≤ 16.7 ms）。零热路径分配（仅在模块加载时建分类表）。
